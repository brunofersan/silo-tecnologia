Instalação

Pronto em poucos minutos

  1. Baixe o instalador

    Clique em “Baixar para Windows” e salve o arquivo no seu computador.

  2. Execute o arquivo

    Dê dois cliques no instalador. Se o Windows exibir “O Windows protegeu o computador”, clique em “Mais informações” e depois em “Executar assim mesmo”.

  3. Siga o assistente

    Aceite a licença, confirme a pasta de instalação e conclua. Ao final, o Silo IDE aparece no menu Iniciar.

  4. Abra e configure

    Na primeira execução, escolha o idioma e o tema, informe a pasta dos seus projetos e, se quiser, cadastre suas conexões de banco.

  5. Mantenha atualizado

    Quando sair uma versão nova, a IDE avisa. Basta confirmar para atualizar, sem reinstalar.

Perguntas frequentes

Dúvidas comuns

O que significa “RC” na versão?

Release Candidate: uma versão candidata, completa e estável para uso, que ainda recebe ajustes finos antes da versão final.

Preciso instalar o Java antes?

Não. O ambiente Java da IDE já vem no instalador. Para compilar seus projetos, você aponta nas configurações o JDK que cada projeto usa.

Qual a diferença entre o instalador e a versão portátil?

O instalador coloca o Silo IDE no menu Iniciar e é o caminho recomendado. A versão portátil vem em uma pasta pronta para usar: basta extrair e abrir, sem instalar, ideal para máquinas sem permissão de administrador.

Funciona em macOS ou Linux?

Por enquanto o instalador é apenas para Windows de 64 bits.

Quais bancos de dados posso acessar?

Bancos com driver JDBC, como Oracle, PostgreSQL, SQL Server e MySQL. Você cadastra as conexões uma vez e alterna entre elas pela aba Banco.

Por que o Windows mostra um aviso ao instalar?

O SmartScreen avisa sobre programas recém-lançados que ainda têm poucos downloads. Baixe sempre por este site, clique em “Mais informações” e em “Executar assim mesmo”.

Como recebo novas versões?

A atualização é automática: a IDE verifica ao iniciar e oferece a nova versão. Suas configurações e projetos são mantidos.

Posso levar minhas configurações para outro computador?

Sim. Use exportar configurações na máquina atual e importar na nova.

Como faço para desinstalar?

Pelo Windows, em Configurações › Aplicativos, como qualquer outro programa.
